# Data requests log / Registre des demandes d'exercice de droits

*GDPR articles 12 and 15 to 22: every request to access, correct, erase, restrict, port or object must be answered within **one month** (extendable by two months for a complex request, with notice to the person in the first month). Keep a line for each, so the association can show it answered.*

How to handle one: `docs/runbook.md`, section "A data request (access or erasure)", with the admin tool **Privacy requests** (`/admin/privacy`).

Keep this file private. **No names or email addresses here**, only a number, the kind and dates. (The admin activity log holds a code for the address, not the address.)
