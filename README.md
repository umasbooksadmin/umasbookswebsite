# Uma's Books and Adventures — website

Single-page website for Uma's Books and Adventures, a non-profit secondhand
English-language bookshop in Albi, France.

## Contents

- `index.html` — the entire site (self-contained: inline CSS, embedded logo, Google Fonts). No build step.

## Working on it

Open `index.html` in a browser. That's it.

The site is also published as a Claude Artifact; edits made here are mirrored there.
